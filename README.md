# melekson.com

## Photo slots

Real photos go in `public/photos/`, using these filenames. Until a file is there, the page shows a tinted box with the caption. Do not add stock photos of people.

| Filename | Where it shows | Caption |
| --- | --- | --- |
| `teaching-class.jpg` | Teaching | Class photo coming soon |
| `teaching-session.jpg` | Teaching | Cohort session photo coming soon |
| `community-gnmcc.jpg` | Community | GNMCC photo coming soon |
| `community-hack-aventura.jpg` | Community | Hack Aventura photo coming soon |

`npm run dev` and `npm run build` refresh the list of files that exist. jpg, png, webp, and avif are accepted.
